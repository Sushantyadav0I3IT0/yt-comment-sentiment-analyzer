# YouTube Comment Sentiment Analyzer

A machine learning project that analyzes the sentiment of YouTube comments and exposes the predictions through a Flask API. The system classifies comments into three categories:

- -1: Negative
- 0: Neutral
- 1: Positive

It combines text preprocessing, a TF-IDF vectorizer, a LightGBM classifier, and a browser extension that lets users inspect comments directly on YouTube pages.

## Overview

This project is designed to:

- collect and preprocess YouTube comment data,
- train a sentiment classification model,
- log model evaluation with MLflow,
- serve predictions via a REST API,
- visualize sentiment trends and summaries,
- integrate with a Chrome extension for browser-based analysis.

## Data Pipeline

The repository uses a DVC-based workflow to build the sentiment model:

```text
data_ingestion -> data_preprocessing -> model_building -> model_evaluation -> model_registration
```

Key files:
- `dvc.yaml` — defines the pipeline stages
- `src/data/data_ingestion.py` — loads raw comment data
- `src/data/data_preprocessing.py` — cleans and transforms text
- `src/model/model_building.py` — trains the model
- `src/model/model_evaluation.py` — evaluates the model
- `src/model/register_model.py` — registers the trained model with MLflow

## Getting Started

### 1) Clone the repository

```bash
git clone https://github.com/Sushantyadav0I3IT0/yt-comment-sentiment-analyzer.git
cd yt-comment-sentiment-analyzer
```

### 2) Create a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3) Install dependencies

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m nltk.downloader stopwords wordnet
```

### 4) Run the DVC pipeline

```bash
dvc repro
```

This step creates the model artifacts:
- `lgbm_model.pkl`
- `tfidf_vectorizer.pkl`

## Run the API

```bash
PORT=5057 python flask_app/app.py
```

Check the health endpoint:

```bash
curl http://localhost:5057/health
```

### Example prediction request

```bash
curl -X POST http://localhost:5057/predict \
  -H "Content-Type: application/json" \
  -d '{"comments":["This is great!","This was disappointing."]}'
```

Example response:

```json
[
  {"comment": "This is great!", "sentiment": "1"},
  {"comment": "This was disappointing.", "sentiment": "-1"}
]
```

## Available API Endpoints

- `GET /health` — checks whether the model artifacts are available
- `POST /predict` — predicts sentiment for a list of comments
- `POST /predict_with_timestamps` — predicts sentiment for comments with timestamps
- `POST /generate_chart` — creates a sentiment distribution chart
- `POST /generate_wordcloud` — generates a word cloud from comments
- `POST /generate_trend_graph` — creates a sentiment trend graph over time

## Docker

Run the training pipeline first so the model files exist, then build and launch the container:

```bash
docker build -t yt-comment-sentiment .
docker run --rm --detach --name yt-comment-api -p 5058:5000 yt-comment-sentiment
```

Then test the application at:

```bash
http://localhost:5058/health
```

## Chrome Extension

The extension is located in `chrome-extension/` and is built for Chrome with Manifest V3.

### Install it locally

1. Open `chrome://extensions`
2. Enable Developer mode
3. Click Load unpacked
4. Select the `chrome-extension` folder
5. Open a YouTube video and load comments
6. Use the extension panel to analyze the visible comments

The extension sends the loaded comment text to your local API running on `http://127.0.0.1:5058`.
